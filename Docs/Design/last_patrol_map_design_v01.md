# LAST PATROL — 에이리넨 마을 지도 설계 v0.1

**레퍼런스**: 핀란드 라플란드 겨울 마을
**뷰**: 직부감 (top-down) — 외부 드라이빙 섹션용

---

## 1. 전체 지도 구조

### 1.1 크기와 단위

- **전체 맵**: 약 2000 × 1600 픽셀 (월드 단위)
- **카메라 뷰**: 640 × 400 (차량 중심 추종)
- **스케일**: 1 픽셀 ≈ 1 미터 (가상 기준)
- 맵 전체는 약 2km × 1.6km의 작은 마을 + 주변 숲

### 1.2 공간 분할

```
                    [북부 숲]
                         │
                    ━━━━━━━━━━
    [서쪽 외곽]  ──  [마을 중심]  ──  [동쪽 주택가]
                    ━━━━━━━━━━
                         │
                   [얼어붙은 호수]
                         │
                    [남쪽 진입로]
```

맵은 다음 5개 구역으로 나뉜다:

| 구역 | 설명 | 주요 기능 |
|---|---|---|
| 마을 중심 | 광장, 경찰서, 교회, 상점들 | 허브, 퀘스트 시작점 |
| 동쪽 주택가 | 단독주택이 밀집 | CH1 사건 현장, 생존자 거주 |
| 서쪽 외곽 | 농장, 임업 작업장, 폐건물 | 강도단 아지트 (CH2) |
| 북부 숲 & 외부 | 자작나무 숲, 폐공장, 대학 | CH3, CH5 원거리 현장 |
| 얼어붙은 호수 | 남쪽 큰 호수 | 저항군 은신처 (CH4) |

## 2. 구역별 상세 설계

### 2.1 마을 중심 (Town Center)

**좌표**: 800-1200 x, 600-1000 y

```
    ┌─────────────────────────────┐
    │     [교회]      [도서관]     │
    │        ⛪           📚        │
    │                              │
    │      [광장] ◆ 크리스마스트리 │
    │                              │
    │  [경찰서]          [식료품점]│
    │     🏛️                 🏪    │
    │                              │
    │  [술집 "타코"]   [주유소]    │
    │     🍺              ⛽        │
    └─────────────────────────────┘
```

#### 주요 건물

**경찰서 (Police Station)** — 허브
- 마렌의 거점. 자고 일어나기, 사건 보드 확인.
- 내부에 죽은 동료들의 책상들 (S10 사이드 퀘스트 대상).
- 차고에 마렌의 순찰 차량.
- 옥상에 안테나 (저항군 라디오 접속점).

**교회 (Church)**
- 신부 **페카**가 거주. 미아의 임시 보호처.
- SubA "교회의 소녀" 시작점.
- 지하에 비밀 통로 (CH5 대학으로 가는 지름길, SubA 완수 시 언락).

**술집 "타코"** — CH2 현장
- 마을 유일한 술집. 검은 새벽 이후 강도단이 점거.
- 외관은 평범하지만 내부는 강도 아지트로 개조.
- CH2 클리어 후 빈 건물로 남음, 이후 사이드 퀘스트 장소로 활용 가능.

**광장 (Square)**
- 마을 중심의 작은 공원. 중앙에 나무 한 그루.
- S7 크리스마스 트리 퀘스트 장소.
- 주변에 유리창 가로등 (조명 장식 참고).

**식료품점 (Grocery)**
- 운영 중단. 문 열려있지만 안은 비어있음.
- 가끔 주인 노인 나타나 물물교환.
- 몇몇 사이드 퀘스트 자원 획득처.

**주유소 (Gas Station)**
- 일부 연료 남아있음. 마렌이 차 연료 보충 가능.
- S5 "주유소의 유령" 장소.

**도서관 (Library)**
- 독서 클럽이 모이는 장소. S9 퀘스트.
- 제이의 대학 코드 관련 참고 자료가 숨어있음 (CH5 힌트).

### 2.2 동쪽 주택가 (East Residential)

**좌표**: 1200-1800 x, 300-900 y

라플란드식 작은 목조 주택 15~20채가 격자형으로 배치. 모든 집이 눈에 덮여있음. 일부는 아직 빛이 나오고, 일부는 어둠.

#### 주요 장소

**노르드만 가족 집 (CH1)** — 1500, 500
- 게임 시작 시 첫 현장.
- 거실, 주방, 2층 침실, 구석방. v11 프로토 그대로.
- 바깥엔 눈밭에 핏자국 흔적.

**살아있는 가족의 집들** — 흩어짐
- 작은 창문에서 빛이 새어나옴.
- 각 집마다 1-2명의 생존자 가족.
- 일부 집은 사이드 퀘스트 발생처.
- **살아남은 창문 카운터**는 이 집들을 기준.

**버려진 집들**
- 창문이 깨져있고 어둠. 가끔 로봇이 순찰.
- 수사 가능한 빈 집들 (자원, 단서).

**농장** — 외곽쪽
- 부부가 운영하던 작은 농장. 부부는 실종/사망.
- 건초더미에 숨겨진 무기 발견 가능.

### 2.3 서쪽 외곽 (West Outskirts)

**좌표**: 200-800 x, 400-1100 y

마을에서 소외된 구역. 임업 작업장과 낡은 창고들이 흩어져 있음.

#### 주요 장소

**임업 작업장 (Sawmill)**
- 폐쇄된 목재 가공 시설.
- 거대한 톱날, 나무 더미, 컨베이어.
- SubB "늙은 수의사" 관련 사건 일부 발생.

**폐건물 단지**
- 구 소비에트식 콘크리트 건물 3-4동 (이 지역 역사적 잔재).
- 강도단이 사용했던 창고.
- CH2 연장선에서 마렌이 조사할 수 있는 장소.

**수의사 카리의 집** — SubB
- 외딴 단독주택. 진료실이 있는 집.
- 지하에 카리가 숨긴 로봇.

### 2.4 북부 숲 & 외부 (North Forest & Beyond)

**좌표**: 800-1800 x, 0-400 y + 맵 밖 확장

마을 북쪽으로 이어지는 자작나무 숲길. 도로가 구불구불 이어짐.

#### 주요 장소

**숲 길**
- 눈 덮인 포장 도로. 양쪽에 자작나무.
- 인카운터 발생 빈도 높음.
- 가끔 도로에 버려진 차량들.

**폐공장 (Abandoned Factory)** — CH3 현장
- 마을 북쪽 15km. 게임에선 "맵 경계 진입 → 다음 맵 로드" 형식.
- 거대한 실내 공간. 강도단과 로봇의 거래소.
- 내부 전투 비중 큼.

**북부 대학 분교 (Northern University)** — CH5 현장
- 50km 북쪽. 별도 로드 맵.
- 연구소 건물 + 기숙사 + 학장실.
- 제이의 지도교수 연구실이 핵심.

### 2.5 얼어붙은 호수 (Frozen Lake)

**좌표**: 400-1600 x, 1100-1600 y

마을 남쪽의 큰 얼어붙은 호수. 두꺼운 얼음 위로 차량 이동 가능.

#### 주요 장소

**저항군 은신처** — CH4 현장
- 호수 서쪽 끝 얼음 아래 숨겨진 벙커.
- 접근하려면 특정 표지판을 찾고 얼음 해치를 통과해야 함.
- 내부는 작은 공동체. 10-15명의 저항군.

**얼어붙은 낚시꾼** — S4 장소
- 호수 중앙 근처 얼음 구멍.
- 노인 혼자 낚시 중. 멋진 초현실적 장면.

**유리병 위치** — S8 장소
- 호수 가장자리 얼음 속에 얼어있는 쪽지 병.

**얇은 얼음 구역** — 위험
- 일부 구역은 얼음이 얇음. 차량 무게로 파손 시 수중 침몰 위험.
- 환경적 퍼즐 요소.

### 2.6 남쪽 진입로 (South Entrance)

**좌표**: 0-2000 x, 1500-1600 y

마을 바깥으로 나가는 유일한 도로. 게임 시작 시 외부로부터 마을로 들어오는 경로이기도.

- **마을 표지판**: "EIRINEN · 인구 3,000 (구)"이라고 쓰인 낡은 표지판.
- **검문소**: 검은 새벽 이전 경찰이 썼던 작은 초소. 지금은 버려짐.
- **외부 맵 연결점**: 이 쪽으로 나가면 다른 지역 맵 로드.

## 3. 차량 이동 시스템

### 3.1 마렌의 순찰차

- **색**: 경찰 흰색 + 파란 줄무늬
- **상태**: 오래되어 덜컹거림. 타이어 체인 장착. 앞유리 금간 자국.
- **HP**: 체력 바 (피격 시 감소)
- **연료**: 제한적. 주유소에서 보충.
- **뒷좌석**: M-07 탑승석.

### 3.2 이동 방식

- **직부감 뷰**.
- **WASD 또는 마우스 클릭 이동**.
- **속도**: 눈길이라 기본 속도 제한. 부스트 가능 (Shift).
- **얼어붙은 호수**: 미끄러움. 조작 더 까다로움.

### 3.3 인카운터

- 드라이빙 중 무작위 인카운터 발생.
- **수사 중 상태**에선 인카운터 빈도 크게 증가.
- 인간형: 뒤에서 차량 추격 → 양쪽 정지 → 하차 총격전
- 로봇형: 드론이 공중에서 공격

## 4. 환경 디테일

### 4.1 시각 레퍼런스 (사용자 제공 이미지 기반)

- **주택**: 목조 1-2층 집. 붉은색/노란색 외벽. 검은색 삼각 지붕.
- **눈**: 지붕, 마당, 도로 가장자리. 도로는 제설되어 부분적으로 보임.
- **조명**: 가로등은 따뜻한 주황색 (halogen). 집 창문은 따뜻한 노랑. 대조적으로 눈은 차가운 파랑.
- **나무**: 자작나무와 전나무. 모두 눈 덮임.
- **전선**: 집 사이 전선줄이 보임. 일부 가로등은 꺼짐.

### 4.2 분위기 디테일

- **빈 집 vs 살아있는 집의 대비**: 빛 있음 / 없음으로 한눈에 구분.
- **연기**: 일부 집 굴뚝에서 연기. 살아있는 신호.
- **발자국**: 마당의 눈에 남은 발자국. 누가 다녀갔는지 단서.
- **잔잔한 눈**: 계속 내리는 듯한 배경 파티클.
- **바람 소리**: 때때로 시야를 가리는 눈보라 이벤트.

### 4.3 동적 요소

- **시간대 변화**: 푸른 황혼 → 깊은 밤 → 새벽 박빛. 하지만 항상 약간 어둡.
- **날씨 변화**: 맑음 → 눈보라 (무작위). 눈보라 시 시야 50% 감소.
- **오로라**: 결정적 장면에서만 등장. 하늘에 초록/보랏빛 커튼.

## 6. 챕터별 맵 사용 흐름

| 챕터 | 시작 지점 | 주요 이동 | 현장 |
|---|---|---|---|
| CH1 | 경찰서 → 동쪽 주택가 | 도로 운전 | 노르드만 집 (실내) |

## 7. 기술적 고려사항

### 7.1 맵 로딩

- **메인 마을 (에이리넨)**: 항상 로드된 상태.
- **원거리 맵 (폐공장, 대학)**: 진입 시 별도 로드.
- **실내**: 진입 시 side-view로 전환 (v11 방식).

### 7.2 성능

- 2000 × 1600 월드는 타일 기반 렌더링 가능.
- 건물은 픽셀 아트 스프라이트.
- 눈과 조명은 파티클 + 오버레이.

### 7.3 반복 요소

- 건물 외관은 4-5개 템플릿으로 조합 (크기, 색상, 세부 변형).
- 나무는 3-4개 템플릿.
- 도로 타일 시스템.
