## 1단계 — 프로젝트 생성 (10분)

### 1.1 프로젝트 만들기

1. Unity Hub → Projects → New Project
2. 템플릿: **3D (URP)**
3. 프로젝트 이름: `LastPatrol`
4. 위치: 로컬 SSD에 (네트워크 드라이브 X, OneDrive 동기화 폴더 X)
5. Create

### 1.2 첫 정리

프로젝트 열리면:
- `Assets/` 안의 `Scenes/`, `Settings/`, `TutorialInfo/` 그대로 둠
- `Assets/` 루트에 `_Project` 폴더 생성 (밑줄 prefix로 항상 맨 위 정렬)
- `Assets/_Project/` 안에 다음 폴더들 만들기:

```
_Project/
├─ Core/
├─ Characters/
│  ├─ Maren/
│  ├─ M07/
│  └─ Enemies/
├─ Systems/
├─ Data/
├─ Scenes/
├─ Art/
└─ Audio/
```

폴더 만들기: Project 창에서 우클릭 → Create → Folder

## 4단계 — 첫 씬 만들기 (20분)

### 4.1 씬 생성

`Assets/_Project/Scenes/` 안에 폴더 `S03_IndoorInvestigation` 만들기.

그 안에 새 씬 생성:
- 우클릭 → Create → Scene
- 이름: `S03_IndoorInvestigation.unity`
- 더블클릭으로 열기

### 4.2 라이팅 기본 셋업

기본 Directional Light 색상을 라플란드 톤으로:
- Hierarchy → Directional Light 선택
- Color: 차가운 푸른빛 약간 (RGB 약 200, 220, 255)
- Intensity: 0.7 (어둑한 황혼)
- Rotation: X=50, Y=-30 (낮은 태양)

Window → Rendering → Lighting:
- Environment → Skybox: 기본 그대로
- Environment Lighting → Source: Color
- Ambient Color: 푸른 회색 (RGB 약 70, 80, 100)

### 4.3 그레이박스 환경 만들기

ProBuilder 또는 기본 Cube로 만들기:

**1F 거실 (가장 단순한 박스):**
- 바닥 Cube: Scale (15, 0.2, 8)
- 뒷벽 Cube: Scale (15, 4, 0.2), Position Z=4
- 좌측벽 Cube: Scale (0.2, 4, 8), Position X=-7.5
- 우측벽 Cube: Scale (0.2, 4, 8), Position X=7.5
- 천장 (선택) Cube: Scale (15, 0.2, 8), Position Y=4

**소파 (엄폐물):**
- Cube: Scale (3, 1, 1.5)
- Position (0, 0.5, 1) — 거실 앞쪽

**책장 (엄폐물):**
- Cube: Scale (1, 2.5, 0.6)
- Position (-6, 1.25, 2)

**시체 위치 표시 (임시):**
- Cube: Scale (1.5, 0.3, 0.5) — 누운 상태 표현
- Color: 어두운 빨강 (혈흔 표시)
- Position (5, 0.15, 0) — 거실 한쪽

이 정도면 첫 그레이박스로 충분.

## 5단계 — 카메라 셋업 (15분)

### 5.1 Cinemachine 가상 카메라

- Hierarchy → 우클릭 → Cinemachine → Virtual Camera
- 이름: `CM_IndoorSideView`
- Position: (0, 3, -8) — 사이드뷰 + 약간 위
- Rotation: (15, 0, 0) — 약간 아래로
- Body: Tracked Dolly 또는 Framing Transposer (마렌 추적용)
- Aim: Composer (마렌 향함)

### 5.2 카메라 추적 대상 설정

CM_IndoorSideView 컴포넌트 인스펙터에서:
- **Follow**: `Maren_Temp` 드래그
- **Look At**: `Maren_Temp` 드래그

이제 마렌이 움직이면 카메라가 따라오면서 사이드뷰 유지.

### 5.3 2.5D 효과를 위한 카메라 설정

진짜 사이드뷰처럼 보이게:
- 메인 카메라 (Main Camera) Projection: Perspective 유지 (Orthographic 아님)
- FOV: 40 (좁은 각도로 깊이감 유지)
- Z 위치를 충분히 멀게 (-10 정도)
- Cinemachine 가상 카메라가 이 메인 카메라를 컨트롤

## 10단계 — 자주 발생하는 문제

**문제: 캐릭터가 바닥을 뚫고 떨어짐**
→ Rigidbody 추가 + Collider 확인. 캐릭터에 Capsule Collider, 바닥에 Box Collider.

**문제: 카메라가 안 따라옴**
→ Cinemachine VirtualCamera의 Follow 설정 확인. 또는 Main Camera에 CinemachineBrain 컴포넌트 있는지 확인.

**문제: Input System 작동 안 함**
→ Project Settings → Player → Active Input Handling을 "Input System Package (New)" 또는 "Both"로.

**문제: Git push 실패 (대용량)**
→ LFS 설정 확인. `git lfs ls-files`로 LFS에 들어갔는지 점검.
